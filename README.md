# The Founders Group

Website for The Founders Group. Built with React, Vite, Three.js and Motion.

- `npm install` then `npm run dev` to work on it locally.
- `npm run build` outputs the site to `dist/`.

Netlify reads `netlify.toml`, so it builds and publishes automatically on every push.

Images: put photos in `public/resources/` (hero.jpg, hero.mp4, collaboration.jpg, ventures/<id>.jpg, founders/<id>.jpg). They appear automatically.
